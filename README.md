# PIX - Media Center for Raspberry Pi

A beautiful media interface designed specifically for Raspberry Pi tablets. Stream your local movie collection with automatic metadata and artwork.

## Try It Live
Visit: https://pix-frontend.duckdns.org

## What Does It Do?
- Automatically finds movie posters and descriptions
- Securely stores your personal media library
- Works on tablets, phones, and computers
- Syncs your collection across devices

## Getting Started
1. Visit the website above
2. Create a free account
3. Start adding your movies
4. Enjoy your personal media center!

## Features
- Automatic movie information lookup
- Private and secure user accounts
- Clean, easy-to-use interface
- Works on any device with a browser
